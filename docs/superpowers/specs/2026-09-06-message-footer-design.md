# Web 消息底部状态栏设计文档

## 一、功能设计

### 1.1 功能概述

Web 聊天界面中，每条助手回复的底部有一个状态栏，用于呈现该次回复的执行状态与结果元信息，解决两个问题：

1. 回复生成过程中，用户无法感知任务已经运行了多久；
2. 回复完成后，用户需要快捷复制整条回复正文，并了解本次回复的总用时与完成时刻。

### 1.2 能力清单

- **实时计时**：回复流式生成期间，底部显示「深度思考中 X秒」，秒数每秒跳动一次，从消息发出时刻起计。
- **复制回复**：回复完成后，底部显示复制按钮，点���将整条回复正文（Markdown 原文）写入剪贴板，并以轻提示反馈结果；剪贴板 API 不可用（如非 HTTPS 环境）时退回 `execCommand` 兜底。
- **总用时**：回复完成后显示「用时 X秒」（超过一分钟显示「X分Y秒」）。
- **完成时刻**���回复完成后显示完成的钟点时间，格式 `HH:MM`（如 `19:01`）。
- **历史回填**：打开历史会话时，每条助手消息同样显示总用时与完成时刻（数据来自会话历史接口的秒级耗时与结束时间戳）；复制按钮同样可用。

### 1.3 设计细节

#### 数据模型（前端 store）

`ChatMessage` 携带三个计时字段（仅助手消息使用）：

| 字段 | 含义 | 来源 |
|------|------|------|
| `startedAt` | 流式开始的墙钟时间戳（ms） | `send()` 创建助手消息时打点 |
| `durationMs` | 整条回复总用时（ms） | 流结束（含停止/出错）时结算；历史消息取 `duration * 1000` |
| `finishedAt` | 完成时刻墙钟时间戳（ms） | 流结束时打点；历史消息取 `timestamp`（该轮结束时间） |

#### 组件

`web/src/components/chat/MessageFooter.vue`，由 `MessageList` 在每条助手消息的正文之后渲染：

- 流式中（`streaming === true`）：渲染加载图标 + 「深度思考中 X秒」，内部以 1 秒间隔的定时器驱动刷新，仅在流式期间运行，组件卸载或流结束即清除；
- 完成后：渲染「复制按钮 + 用时 + 完成时刻」一行，任一信息存在即显示该行，复制按钮仅在正文非空时出现。

#### 文案

中英文案均在 i18n 下的 `chat` 命名空间：`thinkingLive`、`timeUsed`、`durationSec`、`durationMinSec`、`copy`、`copied`、`copyFailed`。

## 二、迭代说明

### 2.1 与上一版差异

- 新增：助手消息底部的 `MessageFooter` 组件（实时计时 / 复制 / 总用时 / 完成时刻）。
- 新增：`ChatMessage` 的 `startedAt`、`durationMs`、`finishedAt` 三个计时字段，流式与历史加载两条路径分别填充。
- 移除：`MessageList` 中「流式且无任何内容时」的独立加载图标，其职责由实时计时行取代。
- 后端无改动：历史回填直接使用会话历史接口已有的 `duration`（秒）与 `timestamp`（结束时间）字段。
