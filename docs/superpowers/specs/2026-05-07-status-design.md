# groot status 命令设计文档

**Goal:** 为 groot 添加实例状态查看子命令，通过调用运行中 groot 实例的 `/health` 接口显示实例运行状态和组件健康信息。

**Architecture:** 新增 `groot status` 子命令，向 `http://127.0.0.1:{port}/health` 发送 HTTP GET 请求，获取 JSON 响应后格式化输出为人类可读的摘要信息。

**Tech Stack:** Go、net/http

---

## 1. 命令用法

```
groot status [-p port]
```

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `-p port` | 否 | 指定 Groot 服务端口，默认从配置读取 | `groot status -p 9090` |
| `-h, --help` | 否 | 显示帮助 | `groot status -h` |

---

## 2. 端口确定逻辑

1. 如果指定了 `-p` 参数，直接使用该端口
2. 否则，加载 `{GROOT_HOME}/config.yaml` 读取 `server.port` 配置
3. 使用确定后的端口向 `http://127.0.0.1:{port}/health` 发送请求

---

## 3. 输出格式

### 3.1 实例运行中

```
Groot 实例状态

状态:      healthy
版本:      1.0.0
运行时间:  2h35m
端口:      8080

组件状态:
  LLM:          healthy (gpt-4o)
  MCP Servers:  healthy (3 个)
  Skills:       healthy (5 个)
  Memory:       healthy (12 个会话)

活跃对话:  1
```

### 3.2 实例未运行（连接失败）

```
未检测到运行中的 Groot 实例（端口 8080）
提示: 请确认 Groot 是否已启动，或使用 -p 指定其他端口
```

---

## 4. 错误处理

| 场景 | 处理 |
|------|------|
| 连接拒绝/超时 | 输出"未检测到运行中实例"提示，正常退出 (exit 0) |
| HTTP 非 200 响应 | 显示状态码，正常退出 (exit 0) |
| 配置加载失败 | 输出错误信息，错误退出 (exit 1) |
| 非法 `-p` 参数 | 输出错误信息，错误退出 (exit 1) |
